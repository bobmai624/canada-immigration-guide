政策关注 · 医疗

境外护士

已有护理教育、执照和真实临床经验的人，优先保留已有职业资产。

  • 先核什么：区分 RN、LPN、医院护工与家庭看护；确认目标省注册资格、近期执业、语言和补课。
  • 具体怎么做：先收集课程及临床时数、原执照与执业记录；向目标省监管机构查申请类别，再查接受境外受训者的雇主。
  • 最易误解：移民清单关注护士，不代表可直接上岗；加拿大工签、注册许可和 PR 是三件事。

政策关注 · 医疗

医生 / 其他持牌医疗人员

医生及物理治疗、药学等职业可能有政策关注，但职业转换通常有较大门槛。

  • 先核什么：确认准确职业、目标省监管机构、认可教育、考试及岗位要求；加拿大经验医生类别不能套给只有境外经验的人。
  • 具体怎么做：把执照转换分成评估、考试、补训、受监督执业、独立执业；每一项取得官方时长与费用依据，再讨论迁移。
  • 最易误解：中国医生转护工不是自动的“低成本平移”；不同职位职责和后续路线会变化。

政策关注 · 技工

焊工 / 电工 / 建筑技工

多年实际工艺和可证明经验，往往比临时补一张短证书更值得先评估。

  • 先核什么：区分技工与助手，核工种是否受强制认证；查联邦技工与省项目各自门槛。
  • 具体怎么做：按项目整理工时、职责、工资、雇主证明和安全培训；向目标省认证机构询问境外经验认可，再测试雇主招聘。
  • 最易误解：建筑业缺人不等于零经验可直接当持牌电工；不能只按中文职位名匹配。

政策关注 · 教育

幼教 / 中小学教师

适合有相关训练、实习、语言与真实教学兴趣的人。

  • 先核什么：幼教与学校教师分开；不同省有不同资格级别。教育学学位不自动等于当地教师执照。
  • 具体怎么做：收集课程描述、教学实习时数和原教师资格；先找监管机构的境外申请章节，再向学校或托育机构查招聘。
  • 最易误解：不能把幼教助理与合格 ECE、补习老师与中小学教师混成一个职业。

关注度高 · 必须核职业

软件 / 网络安全 / 工程

已有可验证技能与项目的人，应先测试岗位市场，再决定是否再留学。

  • 先核什么：软件开发不自动在当前 STEM 类别；网络安全、部分工程职业要逐项核 NOC，工程签章等另涉执照。
  • 具体怎么做：列真实职责与成果，匹配 NOC；选两地收集岗位，标注工作授权、技术栈和本地经验要求，用真实简历测试。
  • 最易误解：“读 STEM 专业”不等于“具备 STEM 类别所需工作经验”，更不等于获邀。

政策关注 · 加拿大研究经验

硕博 / 博士后 / 研究人员

有高学历、论文、研究技术和科研雇佣机会的人，先研究已有专业能否落地。

  • 先核什么：境外博士、加拿大在读博士、受雇博士后不是同一种状态；分类与经验所在地须核。
  • 具体怎么做：保存合同、工资、职责、在读状态和经费期限；向学校核职位是学生资助还是雇员岗位，再复核经验计算。
  • 最易误解：不能把所有奖学金都当工资，不能把全日制学生经验直接计作普通 CEC。

政策关注 · 真实高管经验

高管 / 企业管理雇员

适合实际承担高层决策、预算和组织管理责任者，不按名片头衔判断。

  • 先核什么：普通部门经理与高管有不同 NOC；现行高管类别要求相应加拿大经验，不是境外任职即可套用。
  • 具体怎么做：准备组织架构、权限、预算、汇报关系、工资和任职证据；先核职业及基础 EE，再评估雇佣或企业调动。
  • 最易误解：开一间公司、自封总经理，不会自动产生合格高管经验或企业内调动资格。

高频咨询 · 身份时间

加拿大在读 / 毕业工签持有人

最重要的是课程状态、毕业日、工作权与经验累计能否接上。

  • 先核什么：区分在读、毕业未申请、PGWP 待审、已获 PGWP；每一种工作规则与期限不同。
  • 具体怎么做：在同一张日历标课程完成、许可到期、申请日、合法工作起点及合格经验满一年日；不足的月份必须有备用方案。
  • 最易误解：不能靠再读书自动再领一次 PGWP；拿到工作不等于工作能计入目标项目。

高频咨询 · 多国身份

澳洲 / 英国等第三国留学生或工人

已有海外学习、语言和工作经历可作为资产，但申请加拿大仍需重新查类别。

  • 先核什么：当前所在地、护照、当地居留类型、加拿大许可分别记录。第三国居留并不等于特殊国籍资格。
  • 具体怎么做：保存当地合法居留和工作证据、境外学历、离境与续签安排；先比较 FSW、真实雇主或必要的加拿大学习。
  • 最易误解：外国毕业工签不能换成加拿大 PGWP；短期迁居不会自动改善获批概率。

政策关注 · 法语

有法语基础的职业人士

法语可能增加可研究选项，但不能脱离职业、基础资格与雇主。

  • 先核什么：EE 法语类别看四项 NCLC 7；法语流动工签另看听说、魁省外岗位和雇主条件。
  • 具体怎么做：先测听说读写，取得认可证明；把语言学习计划与现有专业求职结合，不承诺几个月就能过线。
  • 最易误解：有法语不等于有 offer；达到工签语言要求不等于达到 EE 类别要求。

高频咨询 · 雇主与地方限制

司机 / 餐饮零售 / 农业生产

已有真实当地岗位者与境外零经验者，应分开评估。

  • 先核什么：岗位 NOC、TEER、工资、城市、雇主资格、配额窗口、身份都可能改变结果。
  • 具体怎么做：收集合同、工资与实际职责；查当地项目排除职业、雇主支持及 LMIA 受理地图，再问是否真的正在招聘。
  • 最易误解：运输类别不是所有司机；低薪岗位不能因为“缺人”就跳过受理限制；关停窗口不能提前保证重开。

高频咨询 · 核清暂停状态

家庭看护 / 养老照护

职业需求与移民项目是否接收，是两个独立问题。

  • 先核什么：区分家庭看护、医院护工、LPN 和 RN；核当前是否接受新申请及可用工作许可。
  • 具体怎么做：先以真实职责定 NOC，查看官方项目最新公告，核雇主和当前许可；不能用旧课程招生页代替项目状态。
  • 最易误解：不能因课程名写“护理移民”就认定毕业能走已暂停通道。

高频咨询 · 全家分开核

夫妻 / 子女 / 加拿大近亲

先决定谁主申、谁随行、谁是担保人，而不是把全家视为一个身份。

  • 先核什么：配偶工签与团聚 PR 不同；孩子受养与锁龄、学校与监护另核。父母类别有独立接收安排。
  • 具体怎么做：全家逐人记录关系、年龄、身份、工作和学习权；分别计算两种主申方案的费用与时间。
  • 最易误解：在加拿大有兄弟姐妹、成年子女或伴侣，不代表自己自动拿工签或 PR。

高频咨询 · 真经营与资金

企业主 / 高资产人士

适合愿意并能够在当地持续经营的人，不能只看资产总额。

  • 先核什么：企业家、省农场、联邦创业签证的接收状态及要求各自不同；资产、投资和生活资金要分开。
  • 具体怎么做：收集经营报税和资产来源；先核当期开放状态，再做市场验证、现金流和未达业绩的退出方案。
  • 最易误解：买房、买小店或注册公司不等于获得身份；暂停项目不能作为新客现成通道。

基础准备 · 不急于选通道

应届生 / 转行 / 低预算客户

没有成熟职业、经验和资金的人，先明确哪些条件缺失。

  • 先核什么：学历能否被认定、可就业技能、语言及完整支出；不能只对比最便宜学校。
  • 具体怎么做：先做语言诊断与职业试学，取得课程及实习书面资料；比较先在现居地积累经验与立即赴加的成本。
  • 最易误解：学习期间收入不保证覆盖学费；没有合格经验不能只凭专业热门假设可进 EE。

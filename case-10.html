虚构画像 · 用于咨询训练

大陆护照；制造企业股东兼经营者 20 年，大专学历；净资产虚构 800 万人民币，其中可动用 300 万；英语约 CLB4 待测；配偶 57 岁；成年子女已是加拿大 PR，住 BC。没有加拿大现成企业。

给客户的一句话

先分清“想团聚”还是“真愿意经营”。如果只想陪孩子，先核超级签证；父母团聚目前暂停新案，不为等候承诺交移民费用。不要为身份买不懂的生意。

为什么这样选路线

真实经营意愿强时比较 BC Base / Regional 或阿省乡村企业家等。55 岁的 EE 年龄项为零不代表企业家完全不可行；但当地项目评分、经验、语言、资金与商业表现仍要过关。

学什么、做什么

不推荐无关留学来消耗资金。优先英语商务沟通、加拿大行业法规、财务税务和市场尽调。原中国制造经验能否迁移到当地，是商业方案核心。

就业与移民机会怎么判断

维度当前判断（不是统计概率）依据 / 限制
就业 / 经营不使用雇员就业率衡量创业要看客户、订单、毛利、现金流和雇人能力；目前没有市场验证。
移民企业家条件可能值得核查，尚不能确认获邀或履约资金够最低线不是移民成功率高的证据。
团聚成年 PR 子女不能让父母自动成为 PR担保 intake、子女收入和家庭情况另查；超级签证不自动能经营或工作。

线性时间规划

  1. 2026.09—2027.03
    明确生活目标；核资金来源、股权和税务；检查子女担保 / 探亲条件。
  2. 2027
    若真经营，先做考察、商业尽调和社区 / 项目沟通；不在资格明确前买店。
  3. 2028—2029
    如获相应批准及许可，按业绩协议真实经营、雇人和报税；定期查现金流。
  4. 2030—2031
    符合履约条件才申请提名和联邦 PR；如果仅探亲，则维护临时身份，不混称移民完成。

资金与停止投入的边界

300 万可动用现金需划出家庭生活、企业亏损和退出准备。最低合格投资与购房、孩子资助和企业周转不能重复计入；不投入影响退休基本生活的资产。

政策变了，怎么改道

生意不能独立成立，就停止企业家路线；用合规团聚 / 探亲方式处理家人关系。若只愿住温哥华，不应虚构乡村定居承诺申请 Regional。

顾问必须追问的材料与事实
  • 资金来源能否独立核验？
  • 愿不愿亲自每天经营？
  • 是否接受 BC 城外社区生活？
  • 子女收入和现行父母担保机会是否符合？
  • 如果最终没有 PR，这个生意还值得买吗？

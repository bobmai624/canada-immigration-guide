路线 A：已有技能，从境外起步

  1. 2026.09—2027.03
    语言、ECA、NOC 和执照差距；先核 FSW / 省雇主 / 法语 / 社区路线。
  2. 2027 年
    真实招聘与考试；具备全部条件才递交相应工签或 PR；没有雇主就不虚构到岗日期。
  3. 2028—2029 年
    合法工作积累、续签依据、目标邀请 / 提名；有变化则用已有技能改道。
  4. 2029—2031 年
    如已符合并获邀，完成相应 PR 流程；仍未获邀则按预设财务及许可边界决策。

路线 B：两年职业教育，从 2027 入学

  1. 2026.09—2027 开学前
    比较至少两所具体课程；确认职业证照、PGWP/CIP、资金、入学与签证。
  2. 2027—2029 学习期
    每学期查政策、保存全日制与实习记录；合规兼职不当作 CEC 所需经验。
  3. 2029 毕业前后
    及时申请 PGWP；认证、招聘；不能保证立即找到工作。
  4. 2029—2030
    积累能计入的工作，重算 CEC / 省提名 / 社区资格；各省工龄不同。
  5. 2030—2031
    进入竞争与正式审批；如果错过窗口或条件改动，可能超过五年或无法完成。

路线 C：成熟企业家

  1. 前 6—12 个月
    核资金合法来源、商业尽调、考察、社区接洽与语言。
  2. 接下来 1—2 年
    按获批方案及许可真实开办 / 经营；保存工资、采购、税务与经营证据。
  3. 其后
    达到业绩协议才进入提名评估和联邦阶段。生意失败的损失与身份风险单独承担。
计时不是从交钱那天只数审批月数

总时间 = 准备 + 录取 / 招聘 / 认证 + 学习或经营 + 必要工龄 + 等邀请 + 省审批（如适用）+ 联邦审批 + 补件。官网服务标准、历史处理时间、申请人的整体旅程不能混用。

3—5年是观察窗口，不是必须等待的年限

境外已经符合联邦资格，或已具备某省允许境外申请的雇主/社区条件，就现在评估递交。时间轴中的后续年份用于职业发展、身份衔接和未决案件复核；不为了凑满三年而推迟本来可办的申请。

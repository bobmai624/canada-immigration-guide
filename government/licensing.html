名单里有这个职业，也要能合法上岗

先算获得职业资格的难度，再讨论这个职业的移民机会。

同一个NOC，在不同省可能有不同执业门槛

移民选择由移民部门决定；能否做某项工作由省级职业监管机构、行业和雇主决定。一个层面的通过不能替代另一个。

  1. 01确定真实岗位与NOC
  2. 02确认省份及工作环境
  3. 03找政府职业监管入口
  4. 04打开监管机构海外申请页
  5. 05核认可课程/语言/考试/实习
  6. 06估时间与费用后再选课
职业例子要分清什么给普通背景客户的结论
医生 / 31100–31102医学学历、认证、考试、培训/住院医、执照和真实医疗机构岗位；各省类别不同。对已有医学训练者值得逐项评估；从零转行通常不适合低预算、一般英语客户。
律师 / 41101法律教育评估、补课/考试、当地律师资格和执业训练。不能以“受监管职业被列入”推断容易移民或容易就业。
注册护士 / 31301 与 LPN / 32101护理学历、注册类别、语言、考试与近期执业；两种注册体系不能互换。已有护理训练者可能有可执行的转换路径；普通本科不能直接转换成护士。
护理辅助 / 33102 与家庭照护 / 44101工作场景与职责不同；特定省份登记、培训、雇主和健康背景审查。相对短训练仍可能要合格证书、语言及真实雇主；不等于联邦护理试点开放。
幼教 / 42202NOC同时含educator和assistant；省级ECE等级、认可课程和实习不同。先确认读完能注册哪一级，再查职位是否符合通道。
焊工 / 72106、电工 / 72200、水管工 / 72300强制或自愿技工资格、学徒、可认可工时、考试及安全认证按省核。已有可证明实操经验通常优于为移民从零选一个不擅长的工种。
卡车司机 / 73300当地驾照类别、培训、体检、保险与雇主长途经验要求。国内驾照或短期培训不代表能立即获得合格长期offer。

其他省份职业监管机构尚未逐一展开成独立档案。查到机构后，再保存具体“internationally educated / registration requirements”页面；不能只保存机构首页。

顾问应向监管机构问的五个问题

  • 客户现有学历是否进入评估，是否必须重新读完整课程？
  • 语言是移民CLB、学术英语考试还是该机构指定组合？
  • 是否允许在受限/监督执照下工作；该阶段是否符合移民通道？
  • 补课、临床/实习、考试的最长等待和全部费用是多少？
  • 学历认可结论有效多久，政策改变是否有明确过渡保护？

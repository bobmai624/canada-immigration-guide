# 加拿大政府通道目录

研究基准：2026-09-17。静态中文HTML，直接从 index.html 开始。

- 覆盖联邦与全部13个省区。
- 134条通道/子分支/工作许可/特殊或历史记录，不等于134种开放签证。
- 完整516条NOC2021 v1.0职业资料，包含官方任职要求和职责原文。
- 45份职业表或引用索引；对正面、优先、排除、含例外的全文引用分别标注。
- 221条来源档案、94份可用官方截图/官方PDF页面渲染。
- 20个RCIP/FCIP参加社区的官方转介入口；部分当地职业引用已提取，尚未完成所有地方名单与监管细则的人工审核。

所有数据以页面说明的证据深度使用。coverage.html列明未完成核查；policy.html区分现行规则和预测。页面不会提供个人成功概率。

本目录与原知识库日期分开。原虚构画像未改成真实案例，也未上传任何客户证件。

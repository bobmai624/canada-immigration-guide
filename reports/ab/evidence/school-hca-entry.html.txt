<p><a href="https://www.norquest.ca/applying-to-norquest/testing-and-assessment-services/academic-and-placement-assessments/">Accuplacer&nbsp;reading and writing assessment</a>&nbsp;&ndash; Applicants who have submitted an application may be able to meet their&nbsp;academic requirements with a free&nbsp;assessment.&nbsp;Click&nbsp;<a href="/applying-to-norquest/testing-and-assessment-services/academic-and-placement-assessments.aspx" target="_self">here</a>&nbsp;for more details or email&nbsp;<a href="mailto:student.advisor@norquest.ca">student.advisor@norquest.ca</a> to meet with an advisor.</p>

NorQuest College English for Academic Purposes courses may be used to meet academic&nbsp;requirements. See below for details.</p></div>  <div class="col"><p>If you&#39;re missing some academic requirements, you may be able to apply with recognized equivalencies. </div></div></details><details  class="requirements" ><summary>English language proficiency requirements</summary><div>  <div class="col"><p>If English is your second language, you must provide proof of English language proficiency before admission. These results must be no more than two years old when you start your program.</p>

<p>Test scores we accept:</p>

<ul>
	<li>IELTS Academic: 6; no section score below 5.5</li>
	<li>TOEFL iBT: 71</li>
	<li>Duolingo: 95</li>
	<li>CLBA or CLBPA: no section score below 7</li>
	<li>CELPIP General: 7 - No section score less&nbsp;than 6</li>
	<li>CELBAN: No score below: 7 listening, 7 speaking, 7 reading, 7 writing (not an average of 7)</li>
</ul></div>  <div class="col"><p>To be accepted, all applicants must demonstrate English language proficiency (ELP). Explore the <a href="https://www.norquest.ca/applying-to-norquest/how-to-apply/english-language-proficiency-requirements/" target="_blank" title="https://www.norquest.ca/applying-to-norquest/how-to-apply/english-language-proficiency-requirements/">five ways you can meet this requirement</a> at NorQuest.&nbsp;</p>
</div></div></details>  <div><details><summary>Digital Literacy requirements</summary> Candidates must possess knowledge of computer/technology tools to be successful in the program. Candidates must:
<ul>

	<li>Know how to use computer to surf web, email</li>
	<li>Be able to critically evaluate and understand how technology can affect one&#39;s behaviour</li>
	<li>Be able to create, produce content and effectively communication using email, media, Internet</li>
</ul>
</details>

<details><summary>Health Care Aide Workplace Education requirements</summary>

<ul>
	<li>all program admission requirements listed</li>
	<li>must be employed currently as a front-line caregiver with similar HCA responsibilities in a participating agency to be considered</li>
	<li>meet the academic requirements for the program listed above.</li>
	<li>must complete additional workplace Tutor Employment Confirmation Form for consideration for admission into the HCA Workplace program</li>
</ul>
</details>

<details open=""><summary>Transfer Credits</summary>

<p>Up to 50 percent of course credits or hours can be transferred from one Alberta licensed HCA Program to another Alberta licensed HCA Program. See <a href="https://www.norquest.ca/applying-to-norquest/transcripts-and-transfers/transfer-credits/">Transfer Credits</a> for more information.</p>
</details>

<details><summary>Prior Learning Assessment and Recognition (PLAR)</summary>

<p>You may be eligible to receive <a href="https://www.norquest.ca/applying-to-norquest/transcripts-and-transfers/prior-learning-assessment-and-recognition.aspx">Prior learning assessment and recognition</a> for some courses in the program if you have relevant work experience similar to a health care aide or caregiver and wish to meet provincial health care aide certification requirements. Prior learning assessment and recognition, or PLAR, is a way to get credits for your existing knowledge and skills. Testing includes portfolio assessment, examination or skills/lab assessment.</p>

<p><strong>Eligibility</strong></p>

<p>To be eligible for the HCA PLAR, you need to provide proof of the following:</p>

<ul>
	<li>Previous employment, including a job description, totaling 600+ hours within the past three years as an HCA or personal care provider.</li>
	<li>English Language Proficiency requirement (see HCA program admission requirements)</li>
</ul>

<p>Email <a href="mailto:HCAAcademicAdvisor@norquest.ca">HCAAcademicAdvisor@norquest.ca</a> for more information about your eligibility for PLAR into HCA program prior to applying to the HCA program. A PLAR guide and self-assessment will be provided with more information. We recommend starting the PLAR process 6 weeks before your intended program start date.</p>

<p>Visit <a href="https://www.norquest.ca/applying-to-norquest/transcripts-and-transfers/prior-learning-assessment-and-recognition.aspx">Prior learning assessment and recognition</a> for more information about the general PLAR process.</p>
</details></div></details></div></div></section>



<section class="container"><div class="container-grid"><article><h3>Practicum/work experience requirements</h3><p>Before you attend your first practicum, you will need:</p>

<ul>
	<li>to successfully complete all prerequisite courses.</li>
	<li>the following courses. Certificates will be awarded upon completion:
	<ul>
		<li>WHMIS: <a href="/programs-and-courses/courses/xbus1017-whmis-workplace-hazardous-material-information-system/" title="Workplace Hazardous Material Information System (WHMIS)">XBUS 1017</a> (current within three years)</li>
		<li>BLS (CPR): <a href="/programs-and-courses/courses/xhlt1200-basic-life-support-bls-for-health-care-providers/" title="Basic Life Support (BLS) for Health-Care Providers">XHLT 1200</a>. For the duration of your practicum, you must hold BLS for Health Care Provider&rsquo;s certification that has been completed within the last 12 months</li>
		<li>HBPE: <a href="/programs-and-courses/courses/xhlt1023-human-bloodborne-pathogen-exposure/" title="Human Bloodborne Pathogen Exposure">XHLT 1023</a> (current within three years)</li>
	</ul>
	</li>
	<li>a clear <a href="/applying-to-norquest/next-steps-for-accepted-students/completing-work-practicum-and-clinical-requirements.aspx#pic">Police Information Check</a>. A Vulnerable Sector Check is also needed if you are over 18 years of age.</li>
	<li>an up-to-date <a href="/applying-to-norquest/next-steps-for-accepted-students/completing-work-practicum-and-clinical-requirements.aspx#immunizations">immunization record</a>.*</li>
	<li>to complete the&nbsp;<a href="https://www.albertahealthservices.ca/info/page3962.aspx" target="_blank">AHS</a>&nbsp;or&nbsp;<a href="https://covenanthealth.ca/sites/default/files/2023-08/confidentiality-and-user-agreement-form.pdf" target="_blank">Covenant Health</a>&nbsp;information &amp; privacy online learning module.</li>
	<li>to complete the <a href="/NorquestCollege/media/pdf/programs/hspnet-information-sheet-and-consent-form.pdf" target="_blank">HSPNet consent form</a>.</li>
	<li><a href="/applying-to-norquest/next-steps-for-accepted-students/completing-work-practicum-and-clinical-requirements.aspx#n95">N95 mask fit testing</a> arranged by the program (current within two years).</li>
</ul>

<p><sup>*</sup> Immunization requirements:</p>

<ul>
	<li>For full-time, all other part-time, and online delivery students, up to date immunizations must be completed and a record submitted by the To Do list items due dates.</li>
	<li>For regional delivery students, up-to-date immunizations must be completed and a record submitted by the To-do list items due dates.</li>
</ul>

<p>There may be costs associated with completing these requirements. See <a href="/applying-to-norquest/next-steps-for-accepted-students/completing-work,-practicum,-and-clinical-requirements.aspx">Completing work, practicum, and clinical requirements</a> for details and further instructions.</p>

<p><strong>International students:</strong> You must verify your eligibility to proceed with work placements in advance by submitting a copy of your study permit (and a co-op work permit, if you have one) to the International Office (<a href="mailto:international@norquest.ca">international@norquest.ca</a>). See <a href="/internationalstudents/immigration/co-op-work-permit/" target="_blank">Student Work Placement Authorization</a>&nbsp;for more information.</p></article></div><hr></section>

                        <h3>Progression and graduation</h3><p>Students must receive a passing grade in each course to progress through the&nbsp;program. To remain in good academic standing, a minimum term grade point average (GPA) of 2.70 and a passing grade in all Pass/Fail courses (no WF or F) is<br />
required.&nbsp;<br />
<br />
The <a href="https://www.norquest.ca/NorquestCollege/media/pdf/policies/Academic/Academic-Standing-Policy.pdf" target="_blank">Academic Standing Policy</a> and <a href="https://www.norquest.ca/getmedia/8074e8bc-6726-4f2c-a451-647b594fec5d/Academic-Standing-Procedure.pdf" target="_blank">Procedure</a> provide further details on the categories of academic standing, and the consequences and supports available if a student is not in good academic standing.<br />
<br />
A minimum cumulative grade point average (GPA) of 2.70 in the program&rsquo;s courses is required to qualify for graduation.</p>

    let programIntakesRecords = [];
    let todosPages = [];

    let endIndex;
    let pagingList;
    let pagesize = 8;
    var rangestarter = 1;

    var myProgram = document.getElementById('programAbbrSelector').getAttribute('data-abbr');
    let url = "/norquestcollege_program/getprogramintakes?programAbbr=" + myProgram;

    fetch(url, {
        method: 'post',
        headers: {
            'Content-Type': 'application/json'
        },
        //make sure to serialize your JSON body
        body: JSON.stringify({
            programAbbr: myProgram
        })

    })
        .then(response => response.json())
        .then(json => {

            programIntakesRecords = json;

            //paging
            let pagesNumber = programIntakesRecords.length / 8;
            const pagesNumberRemainder = pagesNumber % 1;
            const pagesNumberWithoutRemainder = Math.floor(pagesNumber);
            if (pagesNumberRemainder > 0)
                pagesNumber = Number(pagesNumberWithoutRemainder) + 1;
            todosPages = Array(pagesNumber)
                .fill(1)
                .map((x, i) => i + 1);
            startIndex = 0;
            endIndex = pagesize;
            selectedPage = 1;
            nextPage = selectedPage + 1;

            if (programIntakesRecords.length > 0) {

                //fill the paging list
                injectPagination();

                //start mapping the list
                injectPage();
            }
            else {
                for (let el of document.querySelectorAll('.PaginationIntakes')) el.style.display = 'none';
            }

            if (programIntakesRecords.length < 8) for (let el of document.querySelectorAll('.PaginationIntakes')) el.style.display = 'none';


        });

    injectPagination = () => {

        let html = "";
        //html = `<li class="page-item"><a class="page-link" href="javascript:void(0)" onclick="goPrevious()">***1** Previous</a></li>`;
        for (let page = selectedPage; page <= (programIntakesRecords.length / 8) + 1; page++) {

            //    html += `   <li class="pager__item pager__item--"><a class="page-link" href="javascript:void(0)" onclick="goPrevious()">++9966 ${page}</a></li>`;

            //html += `<li class="pager__item pager__item--next page-item">
            //                <a title="Go to next page" class="page-link" href="javascript:void(0)" onclick="goNext()">
            //                    Next

            //                </a></li>`;

            let previuosLink = " ";
            let nextLink = " ";


            if (programIntakesRecords.length > 8) {
                if (selectedPage > 1) {
                    previuosLink = ` <li class="pager__item pager__item--previous"><a class="page-link" href="javascript:void(0)" onclick="goPrevious(1)"> « Previous</a></li>`;
                }

                if ((selectedPage * 8) < (programIntakesRecords.length)) {
                    nextLink = `<li class="pager__item pager__item--next page-item"><a title="Go to next page" class="page-link" href="javascript:void(0)" onclick="goNext()"> Next »</a></li>`;
                }
            }

            pagingList = previuosLink + printNavigation(selectedPage) + nextLink;
        };

        document.getElementById("paging").innerHTML = pagingList;

        document.getElementById("totalPages").innerHTML = programIntakesRecords.length;
        var rangeEnd = programIntakesRecords.length;

        if (selectedPage != 1)
            rangestarter = startIndex + 1;
        else
            rangestarter = 1;

        if (endIndex < rangeEnd)
            rangeEnd = endIndex;

        document.getElementById("pagesrange").innerHTML = (rangestarter + " - " + rangeEnd);
    };

    injectPage = () => {

        const list = programIntakesRecords
            ? programIntakesRecords
                .slice(startIndex, endIndex)
                .map(
                    (programItem, index) =>

                        `
                                                                                                                 <a OnClick="setYear('${programItem[0]['yearTitle']}','${programItem[0]['monthTitle']}','${programItem[0]['year']}','${programItem[0]['abbr']}','${programItem[0]['intakeid']}');" tabindex='0'>
                                                                                                    <div class="program-tile">
                                                                                                         <h4>${programItem[0]['monthTitleDisplaylbl']} ${programItem[0]['yearDisplaylbl']}</h4>
                                                                                                              <div class="program-tile-info">
                                                                                                                <div>
                                                                                                                  <p><small>Location</small></p>
                                                                                                                  <p><b>${programItem[0]['location']}</b></p>
                                                                                                                </div>
                                                                                                                <div>
                                                                                                                  <p><small>Delivery</small></p>
                                                                                                                  <p><b>${programItem[0]['delivery']}</b></p>
                                                                                                                    ${printIntakeTimeofDay(programItem[0]['timeofday'])}
                                                                                                                </div>
                                                                                                              </div>

                                                                                                              <p><small>Statuses</small></p>
                                                                                                                    <div class="program-statuses">
                                                                                                                    ${printIntakeStatus(programItem[0]['demoesticStatus'], 'Canadian / PR')}
                                                                                                                    ${printIntakeStatus(programItem[0]['IndigenousStatus'], 'Indigenous')}
                                                                                                                    ${printIntakeStatus(programItem[0]['internationalStatus'], 'International')}
                                                                                                                    </div>
                                                                                                            </div>
                                                                                                                  </a>          `
                )
                .join("") //to prevent unexpected comma
            : "";
        document.getElementById("list").innerHTML = list;
    };
    //__________________________________________________________________________________________

    goPrevious = (selectedCountPage) => {
        if (selectedPage != 1) {
            startIndex -= pagesize * selectedCountPage;
            endIndex -= pagesize * selectedCountPage;


            selectedPage--;
            nextPage = selectedPage + 1;
            injectPage();
            injectPagination();
        }
    };

    //__________________________________________________________________________________________
    goNext = () => {
        if (selectedPage < todosPages.length) {

            startIndex += pagesize;
            endIndex += pagesize;



            selectedPage++;
            nextPage = selectedPage + 1;
            injectPage();
            injectPagination();
        }
    };

    //__________________________________________________________________________________________
    goDoubleNext = (count) => {
        if (selectedPage < todosPages.length) {

            startIndex += pagesize * count;
            endIndex += pagesize * count;


            selectedPage = count;


            nextPage = count + 1;
            injectPage();
            injectPagination();
        }
    };
    //__________________________________________________________________________________________
    goPage = (pageNo) => {
        if (pageNo == 1)
            startIndex = 0;
        else {
            startIndex = (pageNo * pagesize) - pagesize;

        }
        endIndex = startIndex + pagesize;

        if (selectedPage <= todosPages.length) {
            selectedPage = pageNo;
            nextPage = selectedPage + 1;
            injectPage();
            injectPagination();
        }
    };
    //__________________________________________________________________________________________

    printNavigation = (selectedPage) => {

                else
                    nav += `<li class="pager__item "><a title="Go to page" class="page-link" href="javascript:void(0)" onclick="goPage(${i})">${i}</a></li>`;
            }
            return nav;
        }
    };

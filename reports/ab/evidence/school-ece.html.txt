The Early Learning and Child Care diploma opens doors to meaningful roles where you can nurture children&rsquo;s development through play and care&mdash;and grow into leadership positions that shape programs, support families, and strengthen communities.&nbsp;</p>

<p class="intro-text">This diploma program prepares you for Early Childhood Educator III certification through the Government of Alberta.&nbsp;</p>
    </article>

</div></div></section></div></section> 

<section class="container 1left"><div class="container-grid"><article><h3>What to expect from the program</h3><p>Recognized by Colleges and Institutes Canada for excellence, the Early Learning and Child Care diploma equips you with the knowledge and skills to provide quality care and create child-centered learning experiences that support healthy development. In the second half of the program, you will build on this foundation by exploring developmental stages, inclusive care, activity planning, management, and social contexts.&nbsp;</p>

<p>Graduates of this program are eligible to apply for&nbsp;<a data-mce-href="https://www.alberta.ca/early-childhood-educator-certification" href="https://www.alberta.ca/early-childhood-educator-certification"><strong>Early Childhood Educator III certification</strong></a>&nbsp;through the Government of Alberta.&nbsp;</p></article><article><h3>Graduate with experience</h3><p>NorQuest College believes in the importance of on-the-job experience that provides an enriched learning opportunity.&nbsp;</p>

<p>You&rsquo;ll graduate from this program with<strong>&nbsp;800 hours of work experience</strong>&nbsp;from four practicums.&nbsp;</p></article></div><hr></section>


<section class="container"><div class=""><h3>Your delivery option</h3> <p>To support your learning experience, this program is offered in the following format:</p><p><strong>In person</strong></p><p>Classes are held in a classroom with face-to-face instruction and regularly scheduled meeting times.&nbsp;</p>
</div><hr /></section>

<section class="container 1left"><div class="container-grid"><article><h3>Already have the Early Learning and Child Care certificate from NorQuest College?&nbsp;&nbsp;</h3>

<p>This program was designed to provide seamless transfer directly into year two of the Early Learning and Child Care - diploma program if you choose to advance your skills and qualifications to the next level. Graduates of the certificate program should apply into year two of the diploma.</p></article></div><hr></section>
<section class="container 1left"><div class="container-grid"><article><h3>Career opportunities</h3><p>Graduates of this program have diverse opportunities to provide child-care services in daycares, preschools, early learning programs, out-of-school care program. or private home-based care.&nbsp;&nbsp;</p>

<p>The child-care field is considered to be an above-average growth profession with increasing annual demand for employees.&nbsp;</p>

<p>For more information on related careers see:&nbsp;</p>

<ul>
	<li><a data-mce-href="https://alis.alberta.ca/occinfo/occupations-in-alberta/occupation-profiles/early-childhood-educator/" href="https://alis.alberta.ca/occinfo/occupations-in-alberta/occupation-profiles/early-childhood-educator/">ALIS OCCinfo occupational profiles</a>&nbsp;</li>
</ul>

<p>This program prepares you to step confidently into your field while providing the flexibility to continue your education. Credits you earn may be transferable toward additional diplomas, degrees, or certifications&mdash;helping you advance your career and increase your earning potential.&nbsp;</p>

<p><a data-mce-href="https://www.norquest.ca/programs-and-courses/programs/early-learning-and-child-care-diploma/" href="https://www.norquest.ca/programs-and-courses/programs/early-learning-and-child-care-diploma/"><strong>Explore transfer pathways</strong></a>.</p></article><article><h3>What to expect as a child care worker or supervisor&nbsp;</h3>

<p><strong>In a typical day, you might:</strong>&nbsp;</p>

<ul>
	<li>Plan and lead activities that encourage creativity, movement, and learning&nbsp;</li>
	<li>Guide children through routines like meals, nap time, and outdoor play&nbsp;</li>
	<li>Communicate with families and work collaboratively with a team&nbsp;</li>
	<li>Maintain a safe, clean, and inclusive environment&nbsp;</li>
	<li>Follow licensing, health, and safety regulations&nbsp;</li>
</ul>

<p><strong>The work is active and hands-on. You may need to:</strong>&nbsp;</p>

<ul>
	<li>Lift and carry young children&nbsp;</li>
	<li>Move quickly to respond to situations&nbsp;</li>
	<li>Spend long periods standing, kneeling, or sitting on the floor.&nbsp;</li>
</ul>

<p><strong>To thrive in this role, you&rsquo;ll need to be:</strong>&nbsp;</p>

<ul>
	<li>Patient, calm, and caring&nbsp;</li>
	<li>Physically active and safety-focused&nbsp;</li>
	<li>Communicative, observant, and organized&nbsp;</li>
	<li>Responsive to children&rsquo;s needs and emotions&nbsp;</li>
</ul></article></div><hr></section>

            'Content-Type': 'application/json'
        },
        //make sure to serialize your JSON body

        })

    })
        .then(response => response.json())
        .then(json => {

            programIntakesRecords = json;

            //paging
            let pagesNumber = programIntakesRecords.length / 8;
            const pagesNumberRemainder = pagesNumber % 1;
            const pagesNumberWithoutRemainder = Math.floor(pagesNumber);
            if (pagesNumberRemainder > 0)
                pagesNumber = Number(pagesNumberWithoutRemainder) + 1;
            todosPages = Array(pagesNumber)
                .fill(1)
                .map((x, i) => i + 1);
            startIndex = 0;
            endIndex = pagesize;
            selectedPage = 1;
            nextPage = selectedPage + 1;

            if (programIntakesRecords.length > 0) {

                //fill the paging list
                injectPagination();

                //start mapping the list
                injectPage();
            }
            else {
                for (let el of document.querySelectorAll('.PaginationIntakes')) el.style.display = 'none';
            }

            if (programIntakesRecords.length < 8) for (let el of document.querySelectorAll('.PaginationIntakes')) el.style.display = 'none';


        });

    injectPagination = () => {

        let html = "";
        //html = `<li class="page-item"><a class="page-link" href="javascript:void(0)" onclick="goPrevious()">***1** Previous</a></li>`;
        for (let page = selectedPage; page <= (programIntakesRecords.length / 8) + 1; page++) {

            //    html += `   <li class="pager__item pager__item--"><a class="page-link" href="javascript:void(0)" onclick="goPrevious()">++9966 ${page}</a></li>`;

            //html += `<li class="pager__item pager__item--next page-item">
            //                <a title="Go to next page" class="page-link" href="javascript:void(0)" onclick="goNext()">
            //                    Next

            //                </a></li>`;

            let previuosLink = " ";
            let nextLink = " ";


            if (programIntakesRecords.length > 8) {

                    previuosLink = ` <li class="pager__item pager__item--previous"><a class="page-link" href="javascript:void(0)" onclick="goPrevious(1)"> « Previous</a></li>`;
                }

                if ((selectedPage * 8) < (programIntakesRecords.length)) {
                    nextLink = `<li class="pager__item pager__item--next page-item"><a title="Go to next page" class="page-link" href="javascript:void(0)" onclick="goNext()"> Next »</a></li>`;
                }
            }

            pagingList = previuosLink + printNavigation(selectedPage) + nextLink;
        };

        document.getElementById("paging").innerHTML = pagingList;

        document.getElementById("totalPages").innerHTML = programIntakesRecords.length;
        var rangeEnd = programIntakesRecords.length;

        if (selectedPage != 1)
            rangestarter = startIndex + 1;
        else
            rangestarter = 1;

        if (endIndex < rangeEnd)
            rangeEnd = endIndex;

        document.getElementById("pagesrange").innerHTML = (rangestarter + " - " + rangeEnd);
    };

    injectPage = () => {

        const list = programIntakesRecords
            ? programIntakesRecords
                .slice(startIndex, endIndex)
                .map(
                    (programItem, index) =>

                        `
                                                                                                                 <a OnClick="setYear('${programItem[0]['yearTitle']}','${programItem[0]['monthTitle']}','${programItem[0]['year']}','${programItem[0]['abbr']}','${programItem[0]['intakeid']}');" tabindex='0'>

                                                                                                                </div>

                                                                                                                  <p><small>Delivery</small></p>
                                                                                                                  <p><b>${programItem[0]['delivery']}</b></p>
                                                                                                                    ${printIntakeTimeofDay(programItem[0]['timeofday'])}
                                                                                                                </div>
                                                                                                              </div>

                                                                                                              <p><small>Statuses</small></p>
                                                                                                                    <div class="program-statuses">

                                                                                                                    </div>
                                                                                                            </div>
                                                                                                                  </a>          `
                )
                .join("") //to prevent unexpected comma
            : "";
        document.getElementById("list").innerHTML = list;
    };
    //__________________________________________________________________________________________

    goPrevious = (selectedCountPage) => {
        if (selectedPage != 1) {
            startIndex -= pagesize * selectedCountPage;
            endIndex -= pagesize * selectedCountPage;


            selectedPage--;
            nextPage = selectedPage + 1;
            injectPage();
            injectPagination();
        }
    };

    //__________________________________________________________________________________________
    goNext = () => {
        if (selectedPage < todosPages.length) {

            startIndex += pagesize;
            endIndex += pagesize;



            selectedPage++;
            nextPage = selectedPage + 1;
            injectPage();
            injectPagination();
        }
    };

    //__________________________________________________________________________________________
    goDoubleNext = (count) => {
        if (selectedPage < todosPages.length) {

            startIndex += pagesize * count;
            endIndex += pagesize * count;


            selectedPage = count;


            nextPage = count + 1;
            injectPage();
            injectPagination();
        }
    };
    //__________________________________________________________________________________________
    goPage = (pageNo) => {
        if (pageNo == 1)
            startIndex = 0;
        else {
            startIndex = (pageNo * pagesize) - pagesize;

        }
        endIndex = startIndex + pagesize;

            nextPage = selectedPage + 1;
            injectPage();
            injectPagination();

            return nav;
        }
    };

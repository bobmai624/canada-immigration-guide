<section class="container"><div class="container-grid"><article><h4>Additional information</h4>

<p>There is a heavy course load in the first term of the Practical Nurse program. We recommend you take the following courses before entering the program:</p>

<ul>
	<li><a href="/programs-and-courses/courses/anph1001-anatomy-and-physiology-i/" title="Anatomy and Physiology I">ANPH 1001</a></li>
	<li><a href="/programs-and-courses/courses/anph1002-anatomy-and-physiology-ii/" title="Anatomy and Physiology II">ANPH 1002</a></li>
	<li><a href="/programs-and-courses/courses/engl2550-introduction-to-composition/" title="Introduction to Composition">ENGL 2550</a></li>
	<li><a href="https://www.norquest.ca/programs-and-courses/courses/heed1000-health-education-individual-health-and-wellness/">HEED 1000</a></li>
	<li><a href="/programs-and-courses/courses/psyc1060-psychology-for-health-care-professions/" title="Principles of Psychology">PSYC 1060</a></li>
	<li><a href="/programs-and-courses/courses/soci1000-introduction-to-the-study-of-society/" title="Introduction to the Study of Society">SOCI 1000</a></li>
</ul>

<p>These courses can be taken through <a href="/programs-and-courses/open-studies.aspx">Open Studies</a> at NorQuest College. Completing these courses allows for better success once you are enrolled. If you intend to apply for full-time student loan funding, contact a retention advisor about your course load before enrolling in Open Studies courses, as this may affect your funding opportunities.</p>

<p>For all deliveries, the Practical Nurse program has a five-year shelf-life regulation on all nursing courses, whether the courses were taken at NorQuest College or transferred from another institution. Visit <a href="/applying-to-norquest/transcripts-and-transfers/transfer-credits.aspx">Transfer credits</a> for more information.</p></article></div></section>

<section class="container"><hr/><div class="container-grid"><article><h3>Practicum/work experience requirements</h3><p>Before you attend your first practicum, you will need:</p>

<ul>
	<li>to successfully complete all prerequisite courses.</li>
	<li>the following courses. Certificates will be awarded upon completion:
	<ul>
		<li>WHMIS: <a href="/programs-and-courses/courses/xbus1017-whmis-workplace-hazardous-material-information-system/" title="Workplace Hazardous Material Information System (WHMIS)">XBUS 1017</a> (current within three years)</li>
		<li>BLS (CPR): <a href="/programs-and-courses/courses/xhlt1200-basic-life-support-bls-for-health-care-providers/" title="Basic Life Support (BLS) for Health-Care Providers">XHLT 1200</a> (current within one year)</li>
		<li>It&#39;s Your Move: <a href="/programs-and-courses/courses/XHLT1070-it-s-your-move/" title="It's Your Move">XHLT 1070</a> (current within one year)</li>
		<li>HPBE: <a href="/programs-and-courses/courses/xhlt1023-human-bloodborne-pathogen-exposure/" title="Human Bloodborne Pathogen Exposure">XHLT 1023</a> (current within three years)</li>
	</ul>
	</li>
	<li>a clear <a href="/applying-to-norquest/next-steps-for-accepted-students/completing-work-practicum-and-clinical-requirements.aspx#pic">Police Information Check</a>. A Vulnerable Sector Check is also needed if you are over 18 years of age.</li>
	<li>an up-to-date <a href="/applying-to-norquest/next-steps-for-accepted-students/completing-work-practicum-and-clinical-requirements.aspx#immunizations">immunization record</a>.</li>
	<li>to complete the&nbsp;<a href="https://www.albertahealthservices.ca/info/page3962.aspx" target="_blank">AHS</a>&nbsp;or&nbsp;<a href="https://covenanthealth.ca/sites/default/files/2023-08/confidentiality-and-user-agreement-form.pdf" target="_blank">Covenant Health</a>&nbsp;information &amp; privacy online learning module.</li>
	<li>to complete the <a href="/NorquestCollege/media/pdf/programs/hspnet-information-sheet-and-consent-form.pdf" target="_blank">HSPNet consent form</a>.</li>
	<li><a href="/applying-to-norquest/next-steps-for-accepted-students/completing-work-practicum-and-clinical-requirements.aspx#n95">N95 mask fit testing</a> (current within two years).</li>
</ul>

<p>There may be costs associated with completing these requirements. See <a href="/applying-to-norquest/how-to-apply/work-practicum-and-clinical-requirements.aspx#practical-nurse">Completing work, practicum, and clinical requirements</a> for details and further instructions.</p>

<p><strong>International students:</strong> You must verify your eligibility to proceed with work placements in advance by submitting a copy of your study permit (and a co-op work permit, if you have one) to the International Office (<a href="mailto:international@norquest.ca">international@norquest.ca</a>). See <a href="/internationalstudents/immigration/co-op-work-permit/" target="_blank">Student Work Placement Authorization</a>&nbsp;for more information.</p></article></div><hr></section>

                    <article>
                        <h3>Progression and graduation</h3><p>Students must receive a passing grade in each course to&nbsp;progress through the program. To remain in good academic standing, a minimum&nbsp;term grade point average (GPA) of 2.00 and a passing grade in all Pass/Fail courses (no WF or F) is required.<br />
<br />
The <a data-mce-href="https://www.norquest.ca/NorquestCollege/media/pdf/policies/Academic/Academic-Standing-Policy.pdf" href="https://www.norquest.ca/NorquestCollege/media/pdf/policies/Academic/Academic-Standing-Policy.pdf">Academic Standing Policy</a> and <a data-mce-href="https://www.norquest.ca/getmedia/8074e8bc-6726-4f2c-a451-647b594fec5d/Academic-Standing-Procedure.pdf" href="https://www.norquest.ca/getmedia/8074e8bc-6726-4f2c-a451-647b594fec5d/Academic-Standing-Procedure.pdf">Procedure</a> provide further details on the categories of academic standing, and the consequences and supports available if a student is not in good academic standing.<br />
<br />
A minimum cumulative grade point average (GPA) of 2.00 in the program&rsquo;s courses is required to qualify for graduation. The program must be completed within five years of your start date.</p>
                    </article>

                    <article>
                        <h3>Honours criteria</h3>
                        <ul>
	<li>Overall grade point average (GPA) greater than or equal to 3.7</li>
	<li>The student must not have failed or repeated any courses</li>
</ul>

    let programIntakesRecords = [];
    let todosPages = [];

    let endIndex;
    let pagingList;
    let pagesize = 8;
    var rangestarter = 1;

    var myProgram = document.getElementById('programAbbrSelector').getAttribute('data-abbr');
    let url = "/norquestcollege_program/getprogramintakes?programAbbr=" + myProgram;

    fetch(url, {
        method: 'post',
        headers: {
            'Content-Type': 'application/json'
        },
        //make sure to serialize your JSON body
        body: JSON.stringify({
            programAbbr: myProgram
        })

    })
        .then(response => response.json())
        .then(json => {

            programIntakesRecords = json;

            //paging
            let pagesNumber = programIntakesRecords.length / 8;
            const pagesNumberRemainder = pagesNumber % 1;
            const pagesNumberWithoutRemainder = Math.floor(pagesNumber);
            if (pagesNumberRemainder > 0)
                pagesNumber = Number(pagesNumberWithoutRemainder) + 1;
            todosPages = Array(pagesNumber)
                .fill(1)
                .map((x, i) => i + 1);
            startIndex = 0;
            endIndex = pagesize;
            selectedPage = 1;
            nextPage = selectedPage + 1;

            if (programIntakesRecords.length > 0) {

                //fill the paging list
                injectPagination();

                //start mapping the list
                injectPage();
            }
            else {
                for (let el of document.querySelectorAll('.PaginationIntakes')) el.style.display = 'none';
            }

            if (programIntakesRecords.length < 8) for (let el of document.querySelectorAll('.PaginationIntakes')) el.style.display = 'none';


        });

    injectPagination = () => {

        let html = "";
        //html = `<li class="page-item"><a class="page-link" href="javascript:void(0)" onclick="goPrevious()">***1** Previous</a></li>`;
        for (let page = selectedPage; page <= (programIntakesRecords.length / 8) + 1; page++) {

            //    html += `   <li class="pager__item pager__item--"><a class="page-link" href="javascript:void(0)" onclick="goPrevious()">++9966 ${page}</a></li>`;

            //html += `<li class="pager__item pager__item--next page-item">
            //                <a title="Go to next page" class="page-link" href="javascript:void(0)" onclick="goNext()">
            //                    Next

            //                </a></li>`;

            let previuosLink = " ";
            let nextLink = " ";


            if (programIntakesRecords.length > 8) {
                if (selectedPage > 1) {
                    previuosLink = ` <li class="pager__item pager__item--previous"><a class="page-link" href="javascript:void(0)" onclick="goPrevious(1)"> « Previous</a></li>`;
                }

                if ((selectedPage * 8) < (programIntakesRecords.length)) {
                    nextLink = `<li class="pager__item pager__item--next page-item"><a title="Go to next page" class="page-link" href="javascript:void(0)" onclick="goNext()"> Next »</a></li>`;
                }
            }

            pagingList = previuosLink + printNavigation(selectedPage) + nextLink;
        };

        document.getElementById("paging").innerHTML = pagingList;

        document.getElementById("totalPages").innerHTML = programIntakesRecords.length;
        var rangeEnd = programIntakesRecords.length;

        if (selectedPage != 1)
            rangestarter = startIndex + 1;
        else
            rangestarter = 1;

        if (endIndex < rangeEnd)
            rangeEnd = endIndex;

        document.getElementById("pagesrange").innerHTML = (rangestarter + " - " + rangeEnd);
    };

    injectPage = () => {

        const list = programIntakesRecords
            ? programIntakesRecords
                .slice(startIndex, endIndex)
                .map(
                    (programItem, index) =>

                        `
                                                                                                                 <a OnClick="setYear('${programItem[0]['yearTitle']}','${programItem[0]['monthTitle']}','${programItem[0]['year']}','${programItem[0]['abbr']}','${programItem[0]['intakeid']}');" tabindex='0'>
                                                                                                    <div class="program-tile">
                                                                                                         <h4>${programItem[0]['monthTitleDisplaylbl']} ${programItem[0]['yearDisplaylbl']}</h4>
                                                                                                              <div class="program-tile-info">
                                                                                                                <div>
                                                                                                                  <p><small>Location</small></p>
                                                                                                                  <p><b>${programItem[0]['location']}</b></p>
                                                                                                                </div>
                                                                                                                <div>
                                                                                                                  <p><small>Delivery</small></p>
                                                                                                                  <p><b>${programItem[0]['delivery']}</b></p>
                                                                                                                    ${printIntakeTimeofDay(programItem[0]['timeofday'])}
                                                                                                                </div>
                                                                                                              </div>

                                                                                                              <p><small>Statuses</small></p>
                                                                                                                    <div class="program-statuses">
                                                                                                                    ${printIntakeStatus(programItem[0]['demoesticStatus'], 'Canadian / PR')}
                                                                                                                    ${printIntakeStatus(programItem[0]['IndigenousStatus'], 'Indigenous')}
                                                                                                                    ${printIntakeStatus(programItem[0]['internationalStatus'], 'International')}
                                                                                                                    </div>
                                                                                                            </div>
                                                                                                                  </a>          `
                )
                .join("") //to prevent unexpected comma
            : "";
        document.getElementById("list").innerHTML = list;
    };
    //__________________________________________________________________________________________

    goPrevious = (selectedCountPage) => {
        if (selectedPage != 1) {
            startIndex -= pagesize * selectedCountPage;
            endIndex -= pagesize * selectedCountPage;


            selectedPage--;
            nextPage = selectedPage + 1;
            injectPage();
            injectPagination();
        }
    };

    //__________________________________________________________________________________________
    goNext = () => {
        if (selectedPage < todosPages.length) {

            startIndex += pagesize;
            endIndex += pagesize;



            selectedPage++;
            nextPage = selectedPage + 1;
            injectPage();
            injectPagination();
        }
    };

    //__________________________________________________________________________________________
    goDoubleNext = (count) => {
        if (selectedPage < todosPages.length) {

            startIndex += pagesize * count;
            endIndex += pagesize * count;


            selectedPage = count;


            nextPage = count + 1;
            injectPage();
            injectPagination();
        }
    };
    //__________________________________________________________________________________________
    goPage = (pageNo) => {
        if (pageNo == 1)
            startIndex = 0;
        else {
            startIndex = (pageNo * pagesize) - pagesize;

        }
        endIndex = startIndex + pagesize;

        if (selectedPage <= todosPages.length) {
            selectedPage = pageNo;
            nextPage = selectedPage + 1;
            injectPage();
            injectPagination();
        }

    //__________________________________________________________________________________________

    printNavigation = (selectedPage) => {

                else
                    nav += `<li class="pager__item "><a title="Go to page" class="page-link" href="javascript:void(0)" onclick="goPage(${i})">${i}</a></li>`;
            }
            return nav;
        }
    };

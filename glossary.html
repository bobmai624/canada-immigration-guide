知识库 / 2026.09.15

术语翻译：第一次咨询只需先懂这些

比喻帮助理解，具体资格仍以相应项目原文为准。

缩写 / 原文像小学生一样理解别混淆
PR · Permanent Resident加拿大永久居民身份。不是国籍，也不是任何一张工作签证。
EE · Express Entry联邦挑选部分经济移民的候选系统。入池不是获邀，更不是批PR。
FSW / CEC / FSTEE常见三扇入场门。符合某个职业类别仍要过基础入口。
CRSEE候选人的排名积分。不等于FSW67分或省EOI分。
EOI · Expression of Interest先举手：告诉项目方我有兴趣和这些条件。通常不是正式PR申请或合法续签依据。
PNP · Provincial Nominee Program省或地区推荐你留下。之后仍需联邦审查；Nunavut没有PNP。
NOC / TEER加拿大按工作职责及培训要求给职业分类。职位名字相同，实际工作不同，代码可能不同。
CLB / NCLC英语 / 法语能力刻度。不是雅思总分；听说读写分别比较。
ECA把境外学历换算成加拿大教育等值。不是学校录取，也不是职业执照。
DLI / CIPDLI是可接收国际生的指定学校；CIP是课程分类代码。学校可招生，不代表每个项目都可PGWP。
PGWP合格毕业生申请的工作许可。通常只发一次；不是移民名额。
LMIA雇主向政府证明需要外国工人的一个评估程序。不是工作许可，也不是PR。
Maintained status · 维持身份符合条件且在到期前申请延长时，按规则等待决定。不是所有申请都有工作权，也不是所有PNP接受。
ITA / LAA / AOR邀请申请 / 曼省申请邀请 / 收件确认，分别是不同阶段文件。每份信能带来什么权利，要看具体项目。
BPA企业家与项目签的经营业绩协议。完成协议才谈后续提名，不是买完生意就完成。
